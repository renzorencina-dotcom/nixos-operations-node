# NixOS Operations Node

Declarative NixOS proof of concept for secure administration, monitoring,
RAID 1 storage, HTTPS access and Restic backups.

## Components

- NixOS 26.05
- OpenSSH
- NixOS firewall
- mdadm RAID 1
- Prometheus and Node Exporter
- Grafana
- Nginx reverse proxy with HTTPS
- Chrony
- Restic
